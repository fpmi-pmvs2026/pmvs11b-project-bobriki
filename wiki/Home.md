# Библиотека — мобильное приложение для Android

## О проекте

**Библиотека** — учебный проект дисциплины ПМВС: мобильная читалка электронных книг с каталогом, обложками, прогрессом чтения и статистикой за месяц. Поддерживаются форматы **EPUB** и **FB2**.

| Параметр | Значение |
|----------|----------|
| Платформа | Android 7.0+ (API 24) |
| Язык | Kotlin |
| UI | Jetpack Compose |
| БД | Room (SQLite) |
| Репозиторий кода | [Library](../README.md) |

## Краткое описание функциональности

1. **Каталог книг** — список с обложкой, автором, прогрессом; импорт из assets и с устройства.
2. **Читалка** — полноэкранное чтение в `ReaderActivity`, навигация по главам, тема и шрифт.
3. **Статистика** — завершённые книги, минуты чтения и суммарный прогресс за текущий месяц.
4. **Внешний API** — Open Library для дополнения метаданных при импорте.
