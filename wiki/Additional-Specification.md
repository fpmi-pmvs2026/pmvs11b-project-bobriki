# Дополнительная спецификация

## Ограничения

| Ограничение | Описание |
|-------------|----------|
| Форматы | Только **EPUB** и **FB2** |
| Хранение | Книги только во внутреннем каталоге приложения |
| Обложки | Извлекаются из EPUB; для FB2 — заглушка |
| Сеть | Требуется для Open Library (опционально при импорте) |
| minSdk | 24 (Android 7.0) |

## Надёжность

- Импорт и парсинг выполняются в `Dispatchers.IO`.
- Ошибки импорта отображаются через Snackbar на главном экране.
- Прогресс чтения сохраняется при выходе из `ReaderActivity`.
- Room обеспечивает атомарные операции insert/update.
- WebView перезагружает HTML только при смене главы или настроек отображения, не при прокрутке.

## Безопасность

| Аспект | Реализация |
|--------|------------|
| Сеть | Только HTTPS к `openlibrary.org` |
| Разрешения | `INTERNET` в манифесте |
| Экспорт Activity | `ReaderActivity` с `exported=false` |
| Пользовательские файлы | Копирование в `filesDir`, без произвольного доступа к чужим данным |
| Резервное копирование | Стандартные правила Android backup |

## Производительность

- Обложки кэшируются в `filesDir/covers/`.
- Список книг обновляется реактивно через `Flow` из Room.
- Парсинг EPUB выполняется по требованию при открытии главы.
- Крупные HTML-главы загружаются в WebView с `baseUrl` для корректного рендеринга.

## Непрерывная интеграция

Файл: `.github/workflows/android-ci.yml`

| Этап | Действие |
|------|----------|
| `build-and-test` | `./gradlew test assembleDebug`, артефакт APK |
| `instrumented-tests` | Эмулятор API 30, `connectedDebugAndroidTest` |

Артефакт сборки: `app-debug.apk`.

## Тестирование

| Тип | Расположение | Описание |
|-----|--------------|----------|
| Unit | `app/src/test/` | Формула прогресса, парсер EPUB (Robolectric) |
| Instrumented | `app/src/androidTest/` | Запуск `MainActivity` |

## Зависимости (основные)

- AndroidX Compose, Material3, Navigation
- Room 2.7, KSP
- Coil (обложки)
- OkHttp 4.12
- Kotlin Coroutines

## Известные ограничения реализации

- DRM-защищённые EPUB не поддерживаются.
- Сложная вёрстка EPUB (CSS, шрифты) упрощается при отображении в WebView.
- Статистика «минут чтения» зависит от записи сессий при выходе из читалки.
